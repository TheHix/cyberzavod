# Киберзавод

Сайт-витрина: изометрический цех в браузере проигрывает записи того, как ИИ-агенты собирают этот же проект. Код открытый, сайт для портфолио.

## Команды

- `npm run check` — типы, тесты и сборка. Должна проходить перед любым коммитом.
- `npm test` — только тесты (`node --test`, файлы `*.test.ts` рядом с кодом).
- `npm run build` — сборка в `dist/`.

## Устройство

- `src/recording.ts` — формат записи сборки и счётчики. Цех рисует только то, что выводится из событий записи; новые визуальные состояния начинаются с нового типа события здесь.
- `public/` — статические файлы, копируются в `dist/` как есть.
- `.claude/agents/` — роли агентов конвейера.

## Правила

- TypeScript strict, без `any`. Идентификаторы на английском, комментарии и тексты интерфейса на русском.
- Импорты внутри `src` — с расширением `.ts` (тесты запускаются Node без сборки).
- Новая логика — с тестом рядом.
- В записи сборок и в репозиторий не должны попадать ключи, токены, адреса серверов и личные данные. Сырые журналы лежат в `recordings/raw/` и в git не идут.
- Небольшие коммиты в формате [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/): `<тип>(<область>): <описание>`. Тип и область на английском (`feat`, `fix`, `docs`, `test`, `refactor`, `ci`, `chore`), описание того, что сделано, — на русском: `feat(recording): добавлен счётчик токенов`. Ломающие изменения — `!` после типа и футер `BREAKING CHANGE:`.
