# Публикация записи сборки

На сайте промпт показывается не так, как его набрали, а в чистовом виде: цель одной строкой и требования списком. Исходный текст (`said`) остаётся в черновике вне git и на сайт не попадает.

## Шаги

1. `make recording-draft` — черновик из самого свежего журнала; другой журнал — `RAW=recordings/raw/<сессия>.jsonl`. Черновик ложится в `recordings/drafts/<id>.json`. Редактура из прошлого черновика той же сессии переносится, команда печатает, что ещё ждёт редактуры.
2. Заполни в черновике `title` и у каждого события `draft_prompt` поля `goal` и `requirements` по правилам ниже. Поле `said` и остальные события не меняй.
3. Покажи человеку заголовок и таблицу: время · как написано (коротко) · цель · требования. Жди явного одобрения. Если есть замечания, исправь и покажи таблицу снова.
4. `make recording-publish` — публикация проверит формат и поищет адреса и ключи, затем запишет `recordings/published/<id>.json`. Если найдено то, что нельзя показывать, перепиши это место, а не обходи проверку.
5. `make check-web`, затем коммит `feat(recordings): опубликована запись «<title>»`.

## Правила чистовой версии

- **Смысл — человека.** Не добавляй требований, которых не было, и не выбрасывай высказанные. Сомнение сохраняй как задачу: «наверно, нужны комментарии, не знаю какие» → «Подобрать стиль комментариев».
- **`goal`** — одна строка до 80 знаков, начинается с глагола в неопределённой форме: «Определить стиль кода», «Объяснить, что такое Let's Encrypt». Короткая реплика тоже получает цель по своему смыслу: «продолжай» → «Продолжить работу», «да, делай» → «Одобрить план и начать».
- **`requirements`** — отдельные пожелания и условия из промпта. Каждое — короткая законченная фраза, без «плюс», «ну», «короче». Если условий нет, список пустой.
- Орфографию и пунктуацию исправь. Термины пиши так же, как в коде: `describe`, JSDoc, `@param`.
- **Не публикуй** адреса серверов, IP, почту, ключи, токены, пароли, имена людей и пути с именем пользователя. Заменяй их общим словом: «адрес сервера», «ключ SSH». Вставленный вывод терминала перескажи одной фразой: «Показать ошибку: сервер просит пароль».
- **`title`** записи — до 60 знаков о сборке в целом: «Стиль кода и публикация записей».

## Пример

Как написано: «слушай добавь над цехом счетчик токенов, ну и время наверно тоже, только чтоб без js если можно»

```json
{
  "goal": "Добавить счётчики над цехом",
  "requirements": [
    "Показывать число токенов",
    "Показывать время, если уместно",
    "Обойтись без JavaScript на странице, если возможно"
  ]
}
```
