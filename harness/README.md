# Harness

Процесс разработки, который Cyberzavod даёт каждому проекту, — независимо от языка, фреймворка и модели. Адаптер агента (первый — Claude Code) превращает эти тексты в файлы, которые понимает его агент; правила конкретного проекта лежат в его AGENTS.md.

- `principles/` — принципы, общие для всех этапов: инженерия, архитектура, объём изменений, безопасность.
- `stages/` — этапы: что делает роль этапа, что получает и в каком виде отвечает. Шапка файла: `role` — имя роли (у этапа без агента её нет), `title` — название для людей, `description` — одна строка о роли, `access` — `read` (только читает) или `write` (меняет файлы).
- `workflows/` — процессы: порядок этапов. `default` — Task → Plan → Implement → Review → Verify → Record.
- `conductor.md` — как ведущий проводит задачу через этапы процесса.

Новый этап — новый файл в `stages/` и новый член `STAGES` в `packages/core/src/stage.ts`; новый процесс — новый файл в `workflows/`.
