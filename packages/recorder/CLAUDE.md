# Запись сборок (packages/recorder)

Хук Claude Code → сырой журнал → запись в формате `@cyberzavod/core`.

- `raw-event.ts` — из полезной нагрузки хука берётся только нужное для записи. Содержимое файлов и ответы инструментов в журнал не попадают.
- `to-recording.ts` — этапы выводятся из действий агента по таблицам `TOOL_STAGES`, `COMMAND_STAGES` и `AGENT_STAGES`. Новый признак этапа — новая строка в таблице, а не новое условие.
- `transcript.ts` — токены из транскрипта; формат транскрипта внутренний, разбор терпимый.
- `record.ts` и `draft.ts` — тонкие точки входа с вводом-выводом; вся логика в чистых функциях с тестами.

Собранная запись всегда проходит `parseRecording` ядра — то же, что записи на сайте.
