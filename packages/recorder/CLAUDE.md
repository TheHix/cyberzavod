# Запись сборок (packages/recorder)

Хук Claude Code → сырой журнал → черновик → редактура промптов → запись в формате `@cyberzavod/core`.

- `raw-event.ts` — из полезной нагрузки хука берётся только нужное для записи. Содержимое файлов и ответы инструментов в журнал не попадают.
- `to-draft.ts` — черновик из журнала. Этапы выводятся из действий агента по таблицам `TOOL_STAGES`, `COMMAND_STAGES` и `AGENT_STAGES`. Новый признак этапа — новая строка в таблице, а не новое условие.
- `draft.ts` — черновик: промпт в нём — событие `draft_prompt` с исходным текстом `said` и чистовой версией `goal` и `requirements`. Пересобранный черновик забирает редактуру из прошлого; публикация убирает `said` и пропускает запись через `parseRecording` ядра.
- `leaks.ts` — страховка публикации: адреса, ключи и личные пути в тексте для сайта. Новый признак — новая строка в таблице.
- `transcript.ts` — токены и ответы моделей из транскрипта: по первому ответу после промпта видно, какая модель его получила. Формат транскрипта внутренний, разбор терпимый.
- `bin/` — тонкие точки входа с вводом-выводом: `record.ts` (хук), `draft.ts` и `publish.ts` (`make recording-draft` и `make recording-publish`). Вся логика — в чистых функциях с тестами.

Исходный текст промпта живёт только в журнале и черновике, оба вне git. Правила чистовой версии — в скилле `.claude/skills/publish-recording/SKILL.md`.
